ApiDelta — 11 mai 2026

À retenir — Anthropic lance Claude Platform sur AWS avec IAM natif ; Mistral SDK Python v2.4.5 introduit des breaking changes dans les réponses des workflows.

Trois points du jour : Claude Platform disponible sur AWS, le header beta 1M tokens retiré sur Sonnet 4.5 et Sonnet 4 (requêtes >200k en erreur), et Mistral Python SDK v2.4.5 casse le parsing des événements workflow. Deux modèles Anthropic expirent le 15 juin.

[INFO] Claude Platform sur AWS : API complète via endpoints AWS natifs

L'API Claude est disponible sur infrastructure AWS gérée par Anthropic avec facturation AWS et authentification IAM. Surface complète : Messages, Files, Message Batches, Managed Agents, Agent Skills, exécution de code, tool use. anthropic-sdk-python v0.101.0 apporte une nouvelle classe client AWS.

Source | SDK

[URGENT] Header beta 1M tokens retiré sur Sonnet 4.5 et Sonnet 4

Depuis le 30 avril, le header context-1m-2025-08-07 n'a plus d'effet sur claude-sonnet-4-5 et claude-sonnet-4-20250514. Les requêtes dépassant 200k tokens retournent une erreur. Migrez vers claude-sonnet-4-6 ou claude-opus-4-6 — la fenêtre 1M y est GA sans header.

Source

[À SURVEILLER] claude-sonnet-4 et claude-opus-4 dépréciés ; retrait le 15 juin

claude-sonnet-4-20250514 et claude-opus-4-20250514 dépréciés le 14 avril, arrêt le 15 juin — dans 35 jours. Remplacements : claude-sonnet-4-6 et claude-opus-4-7.

Source

[URGENT] Mistral Python SDK v2.4.5 : breaking changes dans les réponses de workflow

Deux breaking changes : data.data.union(CustomTaskInProgressResponse).attributes.payload dans workflows.executions.stream() modifié ; data.data dans workflows.events.getstreamevents() modifié. Tout code parsant ces réponses directement cassera à la mise à jour.

Source

[INFO] Anthropic Managed Agents : sessions multi-agents, outcomes et webhooks en bêta publique

Depuis le 6 mai : sessions multi-agents et Outcomes en bêta publique sous managed-agents-2026-04-01. Webhooks couvrant les événements de cycle de vie des sessions et vaults. Rafraîchissement automatique des credentials vault pour mcp_oauth.

Source

[INFO] Gemini 3.1 Flash Lite en GA sur OpenRouter

Modèle multimodal basse latence, haut volume — entrées texte, image, vidéo, audio, PDF. Disponible sur OpenRouter : google/gemini-3.1-flash-lite.

Source

  • Retirer le header context-1m-2025-08-07 de tous les appels vers claude-sonnet-4-5 / claude-sonnet-4-20250514 ; migrer vers claude-sonnet-4-6.
  • Migrer hors de claude-sonnet-4-20250514 et claude-opus-4-20250514 avant le 15 juin.
  • Auditer les intégrations Mistral parsant workflows.executions.stream() ou workflows.events.getstreamevents() avant mistralai v2.4.5.
